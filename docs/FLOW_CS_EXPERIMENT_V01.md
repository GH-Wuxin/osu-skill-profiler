# Flow–CS 实验 V01（未发布）

状态：`EXPERIMENT_ONLY`。本实验没有注册到 release、CLI 或启动脚本，不改变
beta.9.1，也不改变默认 `v010-beta5`。

## 目标

修复 beta.7+ 纯 circle Flow 对 CS 完全不敏感的问题，同时避免在当前 Flow 星数上
直接追加 CS bonus，导致普通高 Flow 整体虚高。

实验保留现有 Flow 的形态、slider-aware 几何、winning window、support 与对数星标尺。
仅将公开 Flow 值反解为原始 `flow_load`，按目标半径重标，再映射回同一星标尺：

```text
base_load  = (2^(base_flow / 3.5) - 1) / 1.55
size_load  = (radius(CS4) / radius(actual_cs)) ^ 0.70
new_flow   = 3.5 * log2(1 + 1.55 * base_load * size_load)
```

设计约束：

- CS4 是中性点，原值不变；
- CS<4 下调，CS>4 上调；
- CS0～12 对正 Flow 严格单调，不设置硬饱和；
- size load 作用于内部负载，不直接加星或乘最终星数；
- base Flow 为 0 时，任意 CS 仍为 0；
- Flow 不成立或证据不足时继续 abstain；
- CS>12 不在本实验范围。

实现：`tools/map_demand_v01/flow_cs_experiment_v01.py`。

## 极端与 Aspire 边界

- legal extreme：p99 `9.381 -> 9.405`，max `10.661 -> 11.298`；最大单图上升
  `+1.616`，来自 CS10 的 A New Summer Adventure! [Archipelago]，
  `1.412 -> 3.028`；
- Aspire：p99 `7.289 -> 7.289`，max `7.293 -> 7.293`；实验不使用 Aspire
  决定参数；
- non-Aspire pathological：p99 `10.545 -> 10.548`，max
  `10.821 -> 10.896`。

实验保留极端图超过 10★ 的能力，没有给普通图设尾部上限，也没有使用 Aspire 压标尺。

## 尚未获得人工确认的假设

1. CS4 作为中性点由主流谱面尺寸决定；
2. `0.70` 来自现有 Flow load 的 velocity exponent；它仍需人工确认；
3. 高 CS 的 Flow 与 Micro Precision 会有机制重叠，本实验未修改 Micro；
4. 本实验只改变 Flow load 的目标尺寸口径，不修订现有 Flow 形态识别；
5. 玩家审查应重点判断 CS2/4/5/6/8/10 的同图次序和间距，而不是只看总体相关性。
