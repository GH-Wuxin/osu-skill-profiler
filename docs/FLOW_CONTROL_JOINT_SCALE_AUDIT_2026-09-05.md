## 2026-09-06：锐角、快慢、局部密度候选 .11（未上线）

撤销 .10 的转向预测函数与重复模式减免。圆圈夹角的锐利程度由入/出单位速度点积得到 `(1-cos(deflection))/2`，作用在原始向量变化量上；再使用原对数变化函数，并保留标量速度变化下界。锐角越小，方向偏转越大，权重越高；没有角度硬门槛，也不按同向/交替模式打折。该几何权重仍是待验证假设，不是人体运动定律。

绝对时间与 CS 仍使用原 adjustment_pressure；八次移动、三秒内的分层证据支持区分局部密集锐角和稀疏锐角，未再叠加一个频率倍率。原有“同向重复不增加 Control”和“同夹角交替必然高于同向”的 .10 测试已替换：现在验证两种转向模式下夹角依次收紧均递增、同排列加快递增，以及同样四次锐角集中于局部窗口时高于分散出现。

| Jungle NM | 6.225 | 7.468 | Control 约 7.5，主要来自圆圈，也有滑条 |
| True DJ NM | 5.321 | 8.577 | Control 约 8.2，圆圈与滑条/衔接都重要 |

Exp4 基线违反 4 条明确区间/上限和 Affection 的跨轴顺序，共 5 条机械可检查条件。这个计数没有把近似点、定性标签和“明显”的未量化幅度当作已通过；更不等于五个独立的人类测试案例。

| 对照 | 机械可检查的违反数 | 判断 |
| --- | ---: | --- |
| 当前两轴 | 5 | 已知条件失败 |
| 同时限 Control + 当前 Flow | 4 | 已知条件失败 |
| 完整阶段 Control，不分段 + 当前 Flow | 4 | 已知条件失败 |
| 已撤下采用资格的相对分段组合 | 4 | 仍失败；且没有充分的绝对调整余裕依据 |
| 持续负荷 Flow + 完整阶段 Control | 5 | 仍失败，另颠倒 Affection / Tower Acme 的 Flow 顺序 |

匹配顺序只表示正负方向相符，不能证明“明显更高”的差距已正确。近似 7.5 / 8.2 只报告残差，没有偷偷增加 ±0.2 或 ±0.5 的通过带。缺失输出按 UNKNOWN 处理，不按零处理。任何组合即使没有明确违反项，也只会得到 NOT_ESTABLISHED，而非自动宣布完成标定。

## 控制变量揭示的结构性质

人工刺激为场内圆圈坐标，固定等弦长规则转弯；没有使用任何人类星数目标。

### 持续长度

固定 CS4、100 ms、45° 转弯，间距 100 px 时，当前 Flow 在 16 次移动为 6.257157，32 / 64 / 128 次均约 6.257174。间距 24 px 时同样从 32 次起维持约 1.850004。当前连续负荷基本只表达最强局部强度与是否建立了足够证据；证据饱和与窗口上限使额外持续长度不再提高主值。

持续负荷原型在 100 px 时给出 6.875 / 8.372 / 9.903 / 11.476，证明它确实具备增长，但这些未校准数值不是正确难度的证明。在真实参照上，该原型给 Affection 7.359、Tower Acme 8.810，违反玩家排序；Blue Zenith 仍仅 5.009。单独更换长度函数不够。

### 转弯与主次

固定间距 60 px、100 ms、64 次移动、CS4：

| 每步转弯 | Flow | Control |
| --- | ---: | ---: |
| 30° | 4.268 | 2.122 |
| 45° | 4.268 | 2.781 |
| 60° | 4.268 | 3.291 |
| 75° | 2.292 | 3.690 |

同一方向变化既降低 Flow 的成员证据，又提高 Control 的向量差，能够造成主次翻转。这是实现机制证据，并非“75° 一定应属于 Flow”的人类标签，也不支持抹掉真正的 Control。

### 时间与目标大小

在 60 px / 45° / 64 次移动下，间隔 240→150→100→75→40 ms，当前两轴均单调升高。该组没有出现 Control 普遍比 Flow 涨得更快的结论，不能凭独立换算系数就断言时间指数是唯一根因。

CS3→4→6 时，同一纯圆圈刺激的 Flow 为 4.039→4.268→4.861，Control 均为 2.781。当前 Control 没有在此刺激上体现目标大小差异。这是需结合 Spatial Precision 轴既有职责审查的范围问题，不能未经定义核实就给 Control 再乘一个 CS 系数。

## 低、中、高、极高训练抽样

从现有 20k QA 中仅选 `strict_disjoint` 的 train 成员；每个谱集最多一张，按校验和确定顺序并覆盖较低/较高滑条占比。NM 总 SR 只用于分层抽样，每档六张：<4、4–6、6–8、≥8。以源文件 MD5 与本地数据库核对采样星数，并校验原有 SHA-256。每张均重新提取 Local Signal 0.4。

这些分段是工程抽样范围，24 张不代表总体分布，也没有人类主轴标签。所有样本 Control 都高于 Flow，不能据此直接宣布 24 张误判。以下仅是后续审查候选：

- Namida no Chikai [KS's Hard] NM：采样总 SR 3.504，Control 4.969。
- BWLAUTE BEIRRD [Resolve] NM（2049344）：采样总 SR 6.196，Control 8.910。
- IMAGE -MATERIAL- <Version 0> [-TERMINAL- <Phase>] NM（3301339）：采样总 SR 8.261，Flow 3.222，Control 9.979。

比较总 SR 与单轴输出用于发现值得审查的案例，不是建立总 SR 上限。未来需要玩家确认熟悉的候选，不要求玩家预先知道算法误判在哪里。独立保留材料未用于打分或拟合。
